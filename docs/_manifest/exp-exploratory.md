# Manifest: Exploratory Default (Claude Code CLAUDE.md)

Sources in scope for the **exploratory-default interlocutor** — the rigorous-but-charitable conversational mode that runs by default in the Claude Code discussion project.

The canonical ranked acquisition list is `../../sources_to_acquire.md`. This manifest tracks **pipeline status** for in-scope sources only.

## Status legend

- `full ✓` — full source PDF in `sources/<slug>/full.pdf`
- `toc ✓` — table of contents (and brief front matter) in `sources/<slug>/toc.md`
- `chunks ✓` — chapters/sections split into `sources/<slug>/chunks/`
- `extracted ✓` — directives extracted to `sources/<slug>/extracted/`
- `not yet acquired` — slug reserved; no folder yet
