## Operational map for the Mode 1 critic skill (and exploratory)

This book is a **reference work**, not a textbook with worked applications. Per Report 2, for **chunking and extraction**:

- **Ch. 1 (p. 7)** — the conceptual framework: what an argumentation scheme is, what critical questions are, why they matter. Required reading for any extraction pass.
- **Ch. 9 (pp. 308–346)** — the compendium of 60 schemes with their paired critical-question sets. **The directly extractable material for a Mode 1 (or exploratory) skill is here.** Each scheme + its critical questions is a self-contained chunk.
- **Chs. 2–5 (pp. 43–188)** — substantive treatment of each scheme cluster (analogy/classification/precedent; knowledge-related; popular-opinion/commitment/character; causal). Use these for the "why" behind each scheme when authoring critic-skill behavior.
- **Ch. 7 (Attack, Rebuttal, and Refutation, p. 220)** — how schemes are deployed dialogically: attacking, questioning, rebutting, refuting. Specifically relevant for the dialogical-engagement aspect of the Mode 1 skill.

For a **first-pass Mode 1 extraction**, the most efficient path is: Ch. 1 (framework) + Ch. 9 (catalog with critical questions). The compendium's compact format makes per-scheme directive extraction nearly mechanical — each scheme already comes paired with the critical questions a critic would ask.

For the exploratory mode (per `_manifest/exp-exploratory.md`), the same Ch. 9 plus selected Ch. 1 framing — the critical questions are precisely the lightweight diagnostic moves the exploratory disposition wants.
